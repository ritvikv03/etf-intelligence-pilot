# Remaining rollout checks

The local workspace now supports the curated collection, composite taxonomy, report-window, analyst review,
and report-library workflow. These rollout checks depend on approved data or an operating environment.

1. **Verify recurring data coverage.** Name owners for the initial feeds. Assess five candidate sources for
   access, reliability, retention, and usefulness. The collector already enforces a ten-source cap and a
   single collection writer. Validate actual publication lag and financial field definitions across funds.
   Realized product revenue and net flows require distinct authoritative observations.
2. **Expand identity and taxonomy coverage.** Review ticker and venue changes and issuer, strategy, asset,
   and investment exposure tags against verified data. Add more tags when analysts can define and review the
   classifications. Keep class and series scope explicit for each financial observation.
3. **Assess historical and point-in-time coverage.** Test archived lookbacks with approved data and verified
   release dates across reporting periods. Since-last-briefing and full-archive windows operate on available
   observations. Strict reconstruction of all historical knowledge and revisions remains a separate data goal.
4. **Evaluate a local model with a real analyst corpus.** Run the evaluator for the installed model and review
   labeled output, classifications, citation accuracy, unsupported statements, and latency. Validate operational
   costs and data handling before adding other models. Reports can use the archived-evidence summary today.
5. **Decide on team deployment and scheduling.** The loopback application and one-shot refresh support
   manual validation. A shared instance needs authentication and ownership. Validate approved network access,
   restart and recovery, and monitoring on the intended host before enabling recurring jobs.
6. **Consider optional web discovery after curated coverage.** Compare incremental relevant coverage with
   permissions review, duplication, and maintenance cost. Source proposals still require analyst review.
